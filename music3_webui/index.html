Lyrics

Section tags: [intro] [verse] [pre-chorus] [chorus] [bridge] [instrumental] [solo] [outro] — each tag goes on its own line (text on the same line as a leading tag is dropped). Duration is an upper bound: the song ends when the lyrics run out.

Music description (caption)

The guide recommends exactly three headings, ~250–450 words: Global Metadata (genre, bpm, key, emotional arc, imagery, production) · Vocal Details (gender & timbre explicitly — the #1 cause of unwanted instrumental drift is leaving vocals unspecified) · Arrangement (primary/secondary instruments and their lifecycle).
